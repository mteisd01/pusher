# Medal Pusher 3D

PCでもスマホ（横向き）でも遊べる、ブラウザ用の本格3Dメダルプッシャーゲームです。
インストールは不要です。PWAに対応しているので、ホーム画面に追加すれば全画面・オフラインでも遊べます。

## 特徴
- **広い盤面に大量のコイン**：幅22列のワイド台に600枚以上のコインが載ります。台の大きさは設定で 22/18/14列 から選べます。
- **リアルなメダル**：刻印の高さマップから法線マップを生成し、旋盤目・擦り傷・縁のギザ、スタジオ照明の映り込み（PBR）を再現しています。画像ファイルは使わず、すべてプログラムで生成しています。
- **本物の物理演算**：Rapier（WASM）で全コインを剛体として計算します。メインスレッドを止めないよう、Web Worker で動かしています。
- **2段構造**：前後に動くプッシャーの上段と下段のフィールドがあり、左右の溝に落ちたコインはロストします（ガード壁で防げます）。
- **スロット**：動く光のゲートにコインを通すと保留が増えます。リーチ演出があり、当たるとコインシャワー・金メダル・レインボーメダル・アイテム・JPボール・フィーバーが出ます。
- **筐体とゲームセンターの空間**：ヘアラインのステンレス、メタリック塗装＋クリアコート、印刷サイドアート、アクリルガラス、LEDドット、スピーカーグリル、内照式マーキーをPBRで描きます。周囲には、カーペット、隣の台、天井照明、ネオンのある店内があり、環境マップにも同じ照明を使っています。前面の受け皿には獲得メダルが実際に溜まります。
- **立体3段クルーンタワー**：JPボールを手前に落とすと、ボールがリフトで画面左のタワーへ運ばれます。螺旋レールを下って回転する皿を3段抜け、最終段のJP穴に入れば積み立て額を総取りです。皿とボールは本物の物理で計算しています。抽選中はカメラがタワーへ寄ります。
- **台上の装置**：
  - 機械式の3Dスロットリール
  - 頭上を動きながらシャワーを流し込むメダルホッパー
  - 上段を不規則に動くキャッチャーカップと、12回入れると回るラッキーホイール
  - 上段に落ちて崩れるメダルタワー
  - 台全体を揺らすシェイク
  - 状況に応じて光る回転灯
- **物理的な仕掛け（v4）**：
  - **ボールコースター**：JPボールは右側のクロームレールを走って登場します。ジグザグ、ループ、2周の螺旋を抜け、分岐器で「フィールド」「スーパー」「プレミアム」に振り分けられます（v6 参照）。
  - **クレーン**：クレーンチャンスでは、照準で左右を合わせてタップします（前後は自動で往復）。3本爪が本物の物理でメダルやアイテムをつかみ、手前まで運んで落とします。持ち上げ中に滑り落ちることもあります。
  - **3Dプリンコ盤**：液晶の前にピン盤が降りてきます。落とす位置を選ぶと、ボールが物理でピンに当たりながら受け口へ落ちます。
  - **回転盤とフリッパー**：フィールド左右の回転盤はフィーバー中と「スピンフィールド」中に回ります。横の溝の入口のフリッパーは、溝際のメダルを中央へ弾き返します。
  - **ボールキッカー**：上段に長く留まったJPボールは、奥の壁から出る押し棒が前へ押し出します。
  - **メーター管**：キャッチャーに入ったメダルがシュートを転がり、ホイール脇のガラス管に溜まります。12枚でホイールが回ります。
- **ボス戦（v5）**：投入とゲート通過でボスゲージが貯まり（通常ペースで約8分）、満タンになると台の奥から3Dのボスがせり上がります。
  - 払い出し、ゲート通過、スロットの当たり、アイテム、クレーン、コンボ、押し出した岩がすべてダメージになります。コアが緑に光る弱点チャンス中は、ゲート通過が5倍のクリティカルです。
  - ボスは4体（岩の巨像／機械竜／深淵獣／時の亡霊）で、それぞれ岩石投げ・ゲート封鎖・メダル吸引・時間凍結（プッシャー減速とガード壁解除）で反撃します。
  - 制限時間内に倒すとメダルとボスの宝箱。倒すたびにステージが進み、HPと報酬が上がります。逃げられると、与えたダメージに応じた残念賞が出ます。HPは液晶に表示されます。
- **難易度6段階（v5）**：やさしい／ふつう／むずかしい／達人／修羅／地獄。
  - 上の難易度ほど、スロット・ゲート・アイテムの確率が渋く、ガード壁が短くなります。むずかしい以上は手前の縁の両端が「OUT」ゾーンになり、そこから落ちたメダルはロストします（幅は難易度で広がります）。修羅と地獄では重い岩がフィールドに落ちてきます。ボスは怒り（達人〜）、自然回復（修羅〜）、バリア（地獄）が加わります。
  - 見返りは、経験値・JPの伸び・宝石のレア度・ボス報酬の倍率と、達人・修羅・地獄でボスを倒すと手に入る限定の称号・テーマ・メダルの見た目です。倍率は上げても払い出し率は上の難易度ほど下がるように、シミュレーターで確かめて調整しています。
- **v6：理不尽さの解消と分かりやすさ**
  - ボスの攻撃はすべて2.5秒前に**予告**され、ゲート封鎖・時間凍結は続けて来ません。ゲートを塞ぐ赤いビームはゲートにメダルを何回か当てると**壊せ**、ボスが3秒スタンします（必要な回数は難易度で5〜14回）。
  - ビッグメダル・レインボー・アイテム・JPボールは**中央寄り（中央から幅の15〜45%）**に落ちます。ホッパーは特別なメダルを目標の位置まで運んでから落とし、JPボールは台の上を渡るレールの光る輪の位置から落ちます。
  - コースターの分岐は **フィールド**（押し出せばクルーン1段目から）／**スーパー**（2段目から）／**プレミアム**（最終段から）。
  - クレーンでつかんだ物は手前の**景品シュート**で2倍払い出し。開始時に光る景品（確定アイテム）が台に置かれます。
  - クレーンやプリンコなど装置を操作している間は、フィーバーなどの残り時間とボスの制限時間が**止まり**、フィーバー・ターボ・獲得2倍などの間は操作の要るチャンスが**保留**されます。
  - 効果が起きるとバナーの下に**一行の説明**が出て、初めての効果は説明カードも出ます。メニューの「**ガイド**」に全部の意味が載っています。説明の出し方は設定の「効果の説明」で「毎回出す／初めてだけ／出さない」から選べます。画面上部のチップには残り時間のバーが付きます。
  - サイドフリッパーは長く強く光るようになり、フィーバー中も作動し、救った枚数を **SAVE** で表示します。すごろくは画面左端の細い帯で表示します。右クリックメニューなどブラウザの動作は出ません。
- **v6：落とす場所だけで遊べる要素**
  - **ナンバーチェッカーとビンゴ**：奥の壁の1〜9の番号板のうち1枚が点滅してから開き、その真下に落としたメダルでビンゴカード（右下）に印が付きます。ライン1本ごとに払い出しが増え、全部そろうとBINGO（大量払い出し＋クルーン2段目からのJP抽選）。
  - **保留変化**：保留は入った時点で結果が決まり、色（白＜青＜金＜虹）で期待度を示します。虹は大当たり確定。
  - **RUSH（連チャン）**：JPの後と、777の半分（突入抽選）で、スロットが6回タダで高速回転し、その間に777が出ると回数が戻って連チャンします。
- **v6：やりこみ**（メニューの「やりこみ」）
  - **4段階JP**：MINI / MINOR / MAJOR / GRAND。JPが出ると液晶が段階を上っていき、止まった段階の額が払い出されます。**JP天井**：外れるほどJP穴が当たりやすくなり、25回外れると次は最終段から大きなJP穴で抽選。
  - **マスタリー**：上限のない強化（払い出し・スロット・JPの伸び・フィーバー・ゲート）。
  - **転生（任意）**：ショップを全部最大にするか一定枚数を獲得すると、進行を戻す代わりに★を得て、ずっと残る★強化を買えます。レベル・宝石・実績・チャームは残ります。
  - **カプセル**：コインでチャーム（ずっと効く小さな効果、重ねてレベルアップ）を引きます。SSRは60回で確定。
  - **BIG / MEGA / EPIC WIN**：RUSH・JP・ビンゴの合計に応じて演出が段階的に派手になります。
  - 調査メモは `docs/endgame_research.md`。
- **ラッキーロード（すごろく）**：ゲート通過やベル揃いなどでサイコロを獲得し、24マスの盤を進みます。1周ごとに大ボーナスがあり、報酬も上がっていきます。
- **ランダムイベント**：ゴールドラッシュ／メテオシャワー／ジャイアントメダル降臨／ハイパープッシャー／ラッキーゲート／タイムチャレンジ／メダルタワー出現／大地震／クレーンチャンス／スピンフィールドが起きます。
- **プリンコ**：落とす位置を選べるパチンコ風のミニゲームです。
- **ボーナスゾーンと中央ポケット**：前縁を流れる光の区画と、時々開く盤面中央の穴があります。
- **プッシュコンボ**：1回の押し出しで大量に落とすとボーナスがもらえます。
- **アイテム**：ガード壁／コインシャワー／ターボ／獲得2倍／フィーバー／保留MAX／プリンコ／サイコロ／マグネット／ボム／シェイク／クレーン／フリッパー の各トークン、宝石、宝箱、ビッグメダルがあります。
- **一時停止**：Pキーかボタンで止められます。メニューを開いている間とタブを隠している間も自動で止まります。
- **サウンド**：Rapier の衝突イベントで鳴らす、モーダル合成の物理音です（コイン同士・鋼板・ガラス・ボールなど）。ほかに、押し出し時のざわめき、受け皿の「ジャラッ」、プッシャーの駆動音、ゲームセンターの環境音があります。BGMはA/Bの展開があるアレンジで、フィーバー・イベント・クルーン用の曲も用意しています。
- **やりこみ要素**：レベル1〜100と称号、12種のショップ強化、約80の実績、デイリーミッション、連続ログインボーナス、宝石図鑑（24種・セットボーナスあり）、統計、9種の台テーマ（6種はレベル、3種は高難易度のボス撃破で解放）と限定メダルの見た目・称号があります。
- **ゲームバランス**：本物の物理とゲームロジックをヘッドレスで回すシミュレーター（`tools/gamesim.mjs`）で収支を測りながら調整しています。何も考えずに投入すると緩やかに減り、ゲート・イベント・強化を活かすと増えるようにしています。難易度は6段階です。
- **充実した設定**：画質プリセットと各項目の個別調整（解像度、影、Bloom、反射、パーティクル、FPS上限、視点、視野角）、物理演算、音量、操作（オート投入、長押し連射、左手レイアウト、UIの大きさ、振動）を変えられます。ゲーム要素は個別にON/OFFでき、アクセシビリティ設定と日本語/英語の切り替えもあります。
- **セーブデータの共有**：圧縮した共有コード、ファイル保存と読込、共有URL（Web Share対応）、QRコードで持ち運べます。盤面のコイン配置も含められます。読み込み前のデータは自動でバックアップします。

## 操作
| 操作 | PC | スマホ |
|---|---|---|
| 投入 | クリック / Space（押しっぱなしで連射） | 画面をタップ（長押しで連射）/ 投入ボタン |
| 投入位置 | マウス移動 / ←→ | 指の位置 |
| オート投入 | A | AUTOボタン |
| 視点切替 / ズーム | C / ホイール | カメラボタン / ピンチ |
| 一時停止 | P | 右上の一時停止ボタン |
| ミュート / 全画面 / FPS | M / F / F3 | 左下ボタン |
| メニュー | Esc | 右上ボタン |

## 開発
```bash
npm install
npm run dev      # 開発サーバー
npm run build    # dist/ に本番ビルド
node tools/sim.mjs 300 420 4      # 物理と払い出し率のヘッドレスシミュレーション
node tools/gamesim.mjs 15 random 4 wide normal  # ゲーム全体の収支シミュレーション（戦略 random / aim / cup、台、難易度。OFF=f_rush,f_bingo で機能を切って比較）
node tools/idle.mjs               # 放置時の微振動と衝突音イベント数の計測
node tools/croonsim.mjs 200 4     # 物理クルーンの穴ごとの分布と所要時間
node tools/ballsim.mjs            # JPボールが出口ごとに獲得されるまでの時間（SIZE / EXIT / TILT）
node tools/plinkosim.mjs          # 物理プリンコの受け口の分布（SWEEP=1 で狙い位置ごと）
node tools/e2e4.mjs http://localhost:5173/ ./out  # コースター・クレーン・プリンコ・フィールド装置のE2E
node tools/e2e5.mjs http://localhost:5173/ ./out  # 難易度・落石・ボス戦のE2E（ONLY=diff,boss）
node tools/e2e6.mjs http://localhost:5173/ ./out  # v6：ボスの予告とビーム破壊、中央寄りの落下、分岐、クレーン、時間停止、UI
node tools/e2e7.mjs http://localhost:5173/ ./out  # v6：保留変化・RUSH・ビンゴ
node tools/e2e8.mjs http://localhost:5173/ ./out  # v6：4段階JP・天井・マスタリー・カプセル・転生
node tools/e2e_reset.mjs          # 初期化・読み込み・復元が再読み込み後も正しいかの検証
node tools/e2e.mjs http://localhost:5173/ ./out   # Playwright によるE2Eスモークテスト
```

`tools/sim.mjs` は、`SNAP=file.json` を付けると飽和した盤面のスナップショットを保存します。`tools/bake.mjs` で `src/data/board_*.txt`（初期盤面）に変換できます。

## 公開（GitHub Pages）
`.github/workflows/deploy.yml` が、push のたびにビルドしてデプロイします。
初回だけ、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に変更してください。

## 構成
- `src/core/` 物理（Rapier、Worker、レイアウト、クレーン・回転盤・フリッパー・キッカー、物理クルーン `croonPhysics.js`、物理プリンコ `plinkoPhysics.js`）
- `src/render/` 描画（シーン、筐体 `cabinet.js`、店内 `room.js`、PBR素材 `materials.js`、クルーンタワー `tower.js`、台上装置 `machines.js`、ボールコースター `coaster.js`、クレーン `crane.js`、3Dプリンコ `plinko3d.js`、フィールド装置 `fieldDevices.js`、ボス `boss3d.js`、コイン、テクスチャ生成、スロット画面、エフェクト、テーマ）
- `src/game/` ゲームロジック（バランス、スロット、進行要素、ボス戦 `boss.js`）
- `src/audio/` 合成サウンドと手続き的BGM
- `src/ui/` HUD、メニュー、ルーレット
- `src/save.js` セーブ、エクスポートとインポート
